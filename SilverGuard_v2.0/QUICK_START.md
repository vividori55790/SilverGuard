# SilverGuard v2.0 - 빠른 시작 가이드

## 🚀 설치 방법

### 1단계: 설치 실행

```
INSTALL.bat 더블클릭 (관리자 권한으로 실행)
```

### 2단계: 프로그램 실행

```
Start_SilverGuard.bat 더블클릭
```

---

## 📋 초기 설정

### 웹 대시보드 접속

- **주소**: http://localhost:8501
- **기본 비밀번호**: `silver1234`

### 필수 설정 항목

1. **텔레그램 봇 토큰** - [@BotFather](https://t.me/BotFather)에서 생성
2. **텔레그램 챗 ID** - [@userinfobot](https://t.me/userinfobot)에서 확인
3. **보호자 연락처** - 긴급 시 자동 전화 발신용

## 🎯 주요 기능

| 기능            | 설명                          |
| --------------- | ----------------------------- |
| **낙상 감지**   | AI가 실시간으로 넘어짐 감지   |
| **음성 확인**   | "괜찮으십니까?" 자동 질문     |
| **자동 알림**   | 텔레그램으로 이미지+영상 전송 |
| **자동 전화**   | 보호자에게 자동 전화 발신     |
| **사생활 보호** | 아바타 모드로 얼굴 비공개     |

## 📱 원격 카메라 설정 (스마트폰)

1. Play 스토어에서 **IP Webcam** 앱 설치
2. 앱 실행 → 하단 "서버 시작"
3. 화면에 표시된 IP 주소 확인 (예: `192.168.0.10:8080`)
4. 대시보드 → 카메라 주소에 입력
5. "원격 카메라 사용" 토글 활성화

## 🔧 문제 해결

### 카메라가 인식되지 않음

- USB 웹캠 연결 확인
- 다른 프로그램에서 카메라 사용 중인지 확인

### 텔레그램 알림이 안 옴

- 봇 토큰/챗 ID 재확인
- 봇과 대화 시작했는지 확인 (/start)

### 시스템이 느림

- 대시보드 → AI 민감도 → 목표 FPS 낮추기 (15~20)
